# Retail Sales Duplicate Record Analysis

## Task Overview
This project focuses on identifying duplicate records in a Retail Sales dataset using Google Sheets. The main objective is to check data quality, identify duplicate entries, and prepare a clean dataset.

## Tools Used
- Google Sheets
- COUNTIF Formula
- Data Cleanup – Remove Duplicates

## Dataset Details
- Dataset: Retail Sales Dataset
- Total Records: 1,002
- Columns include Transaction ID, Date, Customer ID, Gender, Age, Product Category, Quantity, Price per Unit, and Total Amount.

## Tasks Performed
1. Imported the Retail Sales dataset into Google Sheets.
2. Created a working copy of the original dataset.
3. Checked for exact duplicate rows using the Remove Duplicates feature.
4. Checked duplicate Transaction IDs using the COUNTIF formula.
5.Prepared a Duplicate Report.
6.Created a cleaned copy of the dataset.


## Conclusion
The analysis found no duplicate rows or duplicate Transaction IDs in the dataset. Therefore, no records were removed, and all 1,002 records were retained in the cleaned dataset.
